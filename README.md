## 1. Описание проекта

Проект представляет собой модуль промышленной телеметрии нефтяной скважины (`telemetry_cleaner`), реализованный на **чистом Python 3.11+** без использования внешних библиотек анализа данных (`statistics`, `numpy`, `pandas`, `scipy`).

Архитектура проекта выполнена по стандарту **src-layout**:
- `src/telemetry_cleaner/config.py` — конфигурационные пороги и коэффициенты смещения ряда;
- `src/telemetry_cleaner/detectors.py` — математическое ядро (СКО, квартили, Z-score, IQR, фильтрация, импутация);
- `src/telemetry_cleaner/main.py` — консольный интерфейс сравнения детекторов Z-score и Тьюки (1.5·IQR);
- `src/telemetry_cleaner/variant_a.py` — реализация базовой траектории (Вариант А, 12 часов);
- `exercises/run_all_exercises.py` — исследовательский модуль выполнения 7 обязательных упражнений.

## 2. Математические формулы и критерии

### 2.1. Описательные статистики
- **Среднее арифметическое:**
  $$\bar{x} = \frac{1}{n} \sum_{i=1}^n x_i$$
- **Дисперсия генеральная (на $n$):**
  $$D = \frac{1}{n} \sum_{i=1}^n (x_i - \bar{x})^2$$
- **Стандартное отклонение (СКО, $\sigma$):**
  $$\sigma = \sqrt{D} = D^{0.5}$$
- **Медиана ($Med$):**
  Значение центрального элемента отсортированного ряда $x_{(1)} \le x_{(2)} \le \dots \le x_{(n)}$.

### 2.2. Метод Z-оценок ($k \cdot \sigma$)
- **Z-оценка точки:**
  $$z = \frac{|x_i - \bar{x}|}{\sigma} \quad (\text{при } \sigma > 0)$$
- **Коридор нормы:**
  $$[\bar{x} - k\sigma; \; \bar{x} + k\sigma]$$
  Точка признается выбросом, если $z > k$ (по умолчанию $k = 2.0$).

### 2.3. Робастный метод Тьюки ($1.5 \cdot IQR$)
- **Первый квартиль $Q_1$:** медиана младшей половины отсортированного ряда (25-й перцентиль).
- **Третий квартиль $Q_3$:** медиана старшей половины отсортированного ряда (75-й перцентиль).
- **Межквартильный размах ($IQR$):**
  $$IQR = Q_3 - Q_1$$
- **Границы отсечения Тьюки:**
  $$Low = Q_1 - 1.5 \cdot IQR, \quad High = Q_3 + 1.5 \cdot IQR$$

### 2.4. Эффект маскирования (Masking Effect)
Одиночный экстремальный всплеск резко увеличивает дисперсию $D$ и раздувает $\sigma$, из-за чего границы $[\bar{x} - 2\sigma; \bar{x} + 2\sigma]$ становятся неоправданно широкими. В результате умеренные сбои датчика «прячутся в тени» всплеска. Метод Тьюки свободен от этого недостатка, поскольку опирается на робастные порядковые статистики $Q_1$ и $Q_3$.
